JWT Authentication Lab (C# / ASP.NET Core)

Лабораторна №4: автентифікація за токеном JWT.

Запуск

Потрібен .NET 10 SDK та доступ до NuGet під час першого запуску.

Відкрити термінал у папці JwtAuthLab і виконати:

powershell
dotnet restore
dotnet run --urls http://localhost:5000


Відкрити http://localhost:5000

Тестові облікові дані: admin / 123456.

Перевірка

1. Натиснути Увійти й отримати JWT, потім Перевірити токен: повідомлення Доступ дозволено.
2. Натиснути Пошкодити токен, потім Перевірити токен: HTTP 401, недійсний токен.
3. Отримати новий токен, зачекати понад 2 хвилини, натиснути Перевірити токен: HTTP 401, токен прострочений.
4. Ввести неправильний пароль: помилка входу HTTP 401.
